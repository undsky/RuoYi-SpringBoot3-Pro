## Start Your Development Journey

Even if you have **never coded before and haven't written a single line of code**, you can turn an idea into a truly interactive and elegant application in just 5 simple steps by typing single sentences in your AI dialog!

<p align="center">
  <img src="./assets/workflow.gif" alt="DouDou AI Coding Workflow" width="100%" />
</p>

**All commands below are entered directly in the AI dialog window**

---

### Step 1: Equip AI with an "Exclusive Brain"

```
/doudou-wiki init
```

Initialize your knowledge base, and then drop all your reference materials directly into the `kb/raw` directory.

```
/doudou-wiki add
```

Done! Your knowledge base is ready.

### Step 2: Launch the Environment

```
/doudou-dev Help me run the development environment
```

Done! Wait a moment for the services to start...

---

### Step 3: Product Design

```
/doudou-product
```

Done! Product Requirement Documents (PRD), design delivery specifications, database table schemas, development implementation guides, and test acceptance test cases will all be generated into the `resources/product` directory.

---

### Step 4: System Development

- **API & Backend Development**

```
Describe your requirement
```

Code will be automatically generated into the `doudou-eggjs`, `doudou-vue3`, and `doudou-uniapp` directories.

- **Frontend & UI Development**

```
/ui-ux-pro-max Describe your page requirement
```

Done! The page will refresh automatically in a moment, and you can preview the results directly in your browser.

---

### Step 5: Automated Testing

```
/doudou-test
```

Done! Test results and reports will be saved in the `resources/test` directory.
